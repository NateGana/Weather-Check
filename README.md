## 👋 What is RainCheck?

**RainCheck** is a lightweight web application that gives you instant, real-time rain forecasts for any city in the world—or right where you are standing! 

It requires **no installation, no sign-ups, and no setup**. You can just open it in your web browser and start checking the weather!

---

## ✨ Features You'll Love

* **🔍 Instant City Search:** Type any city name and select from live suggestions.
* **📍 One-Tap Geolocation:** Click the location button to automatically fetch the rain forecast for your current spot.
* **☔ Rain Risk Alerts:** Get a clear, color-coded badge (`No Rain`, `Light Drizzle`, or `Heavy Rain Warning`) so you know if you need an umbrella before heading out.
* **📊 Complete Rain Stats:** View exact rainfall amounts (in mm), rain probability (%), humidity levels, and wind speed.
* **🕐 24-Hour Forecast:** Scroll through an hourly breakdown to see when rain is expected to start or stop.
* **⭐ Favorite Locations:** Save your frequently visited cities to a quick-access list that remembers your choices even when you refresh.

---

## 📖 How to Use RainCheck (User Guide)

Using RainCheck is super easy! Here is how to get started:

1. **Search for a Place:** Click on the search bar at the top, type your city name (e.g., *Manila*, *Tokyo*, *London*), and select it from the list.
2. **Or Use Your Location:** Tap the **"Use Current Location"** button to allow your browser to automatically display the weather where you are right now.
3. **Check the Rain Risk:** * 🟢 **No Rain:** Safe to go out!
   * 🟡 **Light Drizzle:** You might want a jacket.
   * 🔴 **Heavy Rain Warning:** Bring an umbrella or stay indoors!
4. **Save Favorite Cities:** Click the star icon next to a city to bookmark it for quick one-click checking next time.
